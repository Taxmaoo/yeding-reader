# 页灯 · TXT 阅读器

页灯在设备上导入和阅读 TXT 小说。书架、正文和阅读进度保存在当前设备的本站浏览器存储中。

## 静态部署

- 将应用目录内的文件一起上传到支持 HTTPS 的静态托管，保留文件名和相对位置，并配置目录首页。可部署在网站根目录或 `/apps/reading-room/` 等子目录。打开目录时请保留末尾的 `/`。服务器应以 `text/javascript` 提供 `.mjs` 文件，以 `application/manifest+json` 提供应用清单。 [目录首页](<./index.html>) · [应用清单](<./manifest.webmanifest>)
- 同一 Wi-Fi 下，可以用 iPhone Safari 访问电脑静态服务器的局域网 HTTP 地址预览页面。安装为网页 App 和离线阅读请用 HTTPS 地址。
- 更新时递增 Service Worker 内的 `VERSION`，将整套静态文件作为同一次发布上传。建议设置 `Cache-Control: no-cache`，让浏览器重新验证 Service Worker。新版资源下载完成后，关闭旧标签页及主屏幕中的页灯，再重新打开即可使用新版。 [版本设置](<./sw.js#L5>)

## 在 iPhone 上使用

1. 用 Safari 联网打开 HTTPS 地址。点「分享」→「添加到主屏幕」→「添加」。若看到「作为网页 App 打开」，请保持开启。
2. 从主屏幕首次打开页灯时保持联网。书架显示「已可离线阅读」后，即可断网重开。
3. 点「导入 TXT」，从 iPhone 的「文件」中选择小说，单本最大 30 MB。左右轻点或滑动可翻页，轻点正文中央打开目录、书签和阅读设置。轻点阅读页中央后，可用进度条两侧的「上一章」和「下一章」跳转。打开目录会定位到当前章，每一章都显示阅读状态和百分比。阅读页已关闭双指缩放和双击放大，改用「Aa 设置」里的字号、行距调整阅读大小。进度会自动保存在本机。
4. 建议定期从书架将小说导出为 TXT，保存到「文件」。TXT 备份包含小说正文，阅读进度保存在本站的本机存储中。清除网站数据会删除本地书架和进度。换设备、域名或协议后，可用备份重新导入。

## 听书功能（支持 iPhone Edge/Safari 锁屏连播）

- 在阅读页点击正文中央打开菜单，点击 **「听书」** 即可开启底部听书控制台，支持朗读段落高亮、自动翻页、语速调节（0.75x–2.0x）、定时关闭（15/30/60 分钟、听完本章）及 iPhone 锁屏/耳机播控。
- **在线 AI 语音模式（推荐）**：接入免费微软 Edge-TTS（晓晓、云希等主播音色）或任意 OpenAI `/v1/audio/speech` 兼容接口，采用防 iOS 锁屏断流机制与双缓冲预加载。服务端部署详见 [免费国内直连部署指南](<./tts-server/README.md>)。
- **浏览器原生朗读模式（离线兜底）**：无需后端服务即可直接朗读。

## 下载番茄小说（含继续下载 / 更新）

书架右上角「⤓ 下载」（手机上为书架里的「⇣ 下载小说」卡片）可以把番茄上的书抓成 TXT 直接进书架。

1. 输入书名、作者，或粘贴 `https://fanqienovel.com/page/<id>` 链接、纯数字 ID。
2. 面板里可改下载章数（默认整本）与抓取节奏：极速 380ms / 标准 1200ms（默认）/ 稳妥 2600ms（每页 6 章）。
3. 下载完成后，书架里这本书的「⋯」菜单会多一项 **「⇣ 继续下载 / 更新」**：
   - 中途点了停止、或某些章被平台拒绝 → 再点它，只补「没下过的章」和「上次失败的章」；
   - 连载书更新后 → 再点它，只追加新发布的章节，不会整本重下；
   - 已经齐全时，面板会显示「已经是最新」。
4. 需要彻底重来可点「重新下载整本」，会用最新内容替换正文，阅读进度与书签保留。

实现要点：

- 每本书在 `books` 记录里带一个 `dl` 字段：`{ remoteId, manifest: [{ id, title, start, end, ok }], total, updatedAt }`，`start/end` 是这一章在正文里的字符区间。
- 追加新章 = 在正文末尾拼接并把新区间写入清单；补失败的章 = 用新区间就地替换，后续条目偏移整体平移。
- 版权页/目录页这类模板章不写正文，但会记入清单（`skipped`），避免每次更新都重复抓取。
- 旧版本下载的书没有清单，会提示「重新下载整本」以补齐清单。

## 下载任务队列

下载不再是一次性的：每次下载都会在本地留一条任务（`localStorage: yeding-dl-tasks-v1`），下载页里的「下载任务（N）」按钮会打开独立的任务面板。

- **状态**：等待中 / 下载中 / 已暂停 / 已停止 / 已完成 / 失败；
- **暂停**：立刻停发请求，已取到的章按清单落盘（不会丢）；
- **继续**：按「目标范围 − 已有清单」做差集，只补没下的章，不会从头重取；
- **补漏**：跑完仍有失败章时，自动做 4 轮延时重试（2s/5s/12s/25s，从第 2 轮起换设备身份）；仍失败则在任务行出现「补漏（N 章）」按钮，可手动再来一轮；
- **刷新/关站**：页面一刷新，之前标记「下载中」的任务会自动归位成「已暂停（页面已关闭）」，点继续即可接着下；
- 同一本书只保留一条任务，重复下载会复用而不是堆叠。
