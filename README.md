# 页灯 · TXT 阅读器

页灯在设备上导入和阅读 TXT 小说。书架、正文和阅读进度保存在当前设备的本站浏览器存储中。

## 静态部署

- 将应用目录内的文件一起上传到支持 HTTPS 的静态托管，保留文件名和相对位置，并配置目录首页。可部署在网站根目录或 `/apps/reading-room/` 等子目录。打开目录时请保留末尾的 `/`。服务器应以 `text/javascript` 提供 `.mjs` 文件，以 `application/manifest+json` 提供应用清单。 [目录首页](<./index.html>) · [应用清单](<./manifest.webmanifest>)
- 同一 Wi-Fi 下，可以用 iPhone Safari 访问电脑静态服务器的局域网 HTTP 地址预览页面。安装为网页 App 和离线阅读请用 HTTPS 地址。
- 更新时递增 Service Worker 内的 `VERSION`，将整套静态文件作为同一次发布上传。建议设置 `Cache-Control: no-cache`，让浏览器重新验证 Service Worker。新版资源下载完成后，关闭旧标签页及主屏幕中的页灯，再重新打开即可使用新版。 [版本设置](<./sw.js#L5>)

## 在 iPhone 上使用

1. 用 Safari 联网打开 HTTPS 地址。点「分享」→「添加到主屏幕」→「添加」。若看到「作为网页 App 打开」，请保持开启。
2. 从主屏幕首次打开页灯时保持联网。书架显示「已可离线阅读」后，即可断网重开。
3. 点「导入 TXT」，从 iPhone 的「文件」中选择小说，单本最大 30 MB。左右轻点或滑动可翻页，轻点正文中央打开目录、书签和阅读设置。轻点阅读页中央后，可用进度条两侧的「上一章」和「下一章」跳转。打开目录会定位到当前章，每一章都显示阅读状态和百分比。进度会自动保存在本机。
4. 建议定期从书架将小说导出为 TXT，保存到「文件」。TXT 备份包含小说正文，阅读进度保存在本站的本机存储中。清除网站数据会删除本地书架和进度。换设备、域名或协议后，可用备份重新导入。
